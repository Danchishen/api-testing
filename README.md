# Тестирование API сервиса Restful-Booker

В данном репозитории представлены результаты выполнения тестового задания 
## Состав проекта
* `collection.json` — экспортированная коллекция Postman (v2.1) 
* `Test_cases.xlsx` — файл со спроектированными позитивными и негативными тест-кейсами.
* `Bug.xlsx` — баг-репорты, оформленные по результатам обнаруженных дефектов.

## Описание коллекции Postman
Коллекция разбита на логические папки по эндпоинтам:
1. `Auth` — генерация токена доступа. Реализовано автоматическое сохранение токена в переменную коллекции для авторизации последующих запросов.
2. `Booking` — полный CRUD цикл создания, получения, изменения (PUT) и удаления бронирования. Идентификаторы бронирований (`bookingId`) сохраняются динамически и передаются между запросами автоматически.
3. `Ping` — проверка доступности сервиса.

## Инструкция по запуску тестов
1. Склонируйте репозиторий или скачайте файл коллекции.
2. Импортируйте файл `collection.json` в Postman.
3. Убедитесь, что в переменных коллекции указан URL.
